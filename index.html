Palo Alto Networks

Software Engineering InternBuilt CommitGuard, an AI-assisted workflow for finding relevant firewall tests and running them in a virtual test environment.Show detailsHide details

CommitGuard pipeline

1 · ScanParse test functions and metadata from the test repository.
2 · EmbedCreate 3,072-dimensional semantic embeddings with Vertex AI.
3 · IndexStore vectors and metadata in Qdrant.
4 · SearchUse YAML feature inputs for semantic and keyword search; merge rankings with RRF and rerank candidates.
5 · ExecuteSelect and run tests in a virtual firewall environment; stream output to the browser.

What I built

  • Developed an asynchronous FastAPI service with search, test selection, and execution workflows.
  • Used tree-sitter AST parsing to extract test metadata without executing source files, then indexed thousands of tests for retrieval.
  • Combined embedding search, keyword matching, reciprocal rank fusion, and Gemini reranking to improve relevance; search returned results in under a second after indexing.
  • Connected selected tests to the team’s automation framework and streamed execution output through server-sent events.

Impact

Engineers could find relevant tests in seconds instead of manually reviewing the repository. The system was deployed for the engineering team and validated with functional tests against virtual firewalls.

AI & ML InternBuilt an AI research platform combining literature search, graph generation, and predictive modeling.Show detailsHide details

Research platform pipeline

1 · IngestCollect hundreds of scientific papers and associated research data.
2 · PrepareClean, structure, and chunk research content for retrieval.
3 · IndexGenerate embeddings and store searchable vectors in Pinecone.
4 · RetrieveEmbed a researcher's query and find relevant content by semantic similarity.
5 · AnswerGround LLM responses in retrieved research context.
6 · AnalyzeGenerate research graphs and use regression models to explore outcomes and trends.
7 · DeliverStream results through a React chatbot backed by cloud services and databases.

My contribution

  • Built the end-to-end RAG chatbot and integrated Pinecone retrieval across hundreds of papers.
  • Used Python and C++ for data preprocessing and C++ for vector similarity calculations.
  • Integrated graph generation and regression modeling to help researchers inspect relationships and predictions.
  • Developed a React interface with streaming responses and worked with Heroku, AWS, and MySQL RDS for backend data services.

How retrieval worked

Research papers were prepared as searchable text chunks, converted to embeddings, and indexed in Pinecone. A query retrieved related passages, which provided context for an LLM response streamed to the researcher.
